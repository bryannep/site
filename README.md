# Bryanne Peterson

An executive portfolio exploring how organizations learn, align, and decide through trustworthy evidence.

## Purpose

This site is intentionally not a traditional portfolio.

Rather than documenting projects chronologically, it presents the systems, frameworks, and ideas I have developed to improve how organizations generate, integrate, and act on evidence.

Projects serve as evidence.

Ideas are the product.

## Design Philosophy

The site should read more like an executive strategy book than a portfolio.

Every section begins with an organizational challenge or observation.

Every capability demonstrates an organizational principle.

Every exhibit provides supporting evidence.

## Typography System

The interface uses five recurring text roles:

1. Label
2. Display
3. Deck
4. Body
5. Caption

Hierarchy should be communicated primarily through order, spacing, and scale—not by inventing a new style for each component.
