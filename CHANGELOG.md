# Changelog

## v0.18

### Content architecture

- Reframed the site around organizational capabilities rather than projects
- Clarified the Learn → Align → Decide structure
- Established a principle-first content model
- Defined projects as supporting evidence rather than the primary narrative
- Introduced a stronger hierarchy between flagship capabilities, supporting capabilities, and supporting ideas

### Design system

- Expanded the Exhibit system
- Defined supported exhibit types: video, diagram, case study, slide, framework, and document
- Clarified the relationship among Field Notes, Exhibits, and Essays
- Added the rule that every major capability should end by making its principles tangible through exhibits

### Writing system

- Added statement-first section structure
- Project names now function as supporting examples
- Reduced résumé-style language
- Shifted evidence and impact language toward organizational capability and transformation
- Established present-tense language for reusable principles and flip-card content
